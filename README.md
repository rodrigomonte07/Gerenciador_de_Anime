# 🎌 Gerenciador de Anime

Um projeto simples desenvolvido com **HTML, CSS e JavaScript** para gerenciar uma lista de animes de forma dinâmica.

## 📋 Funcionalidades

- ➕ Adicionar novos animes
- 🖼️ Inserir imagem do anime através de URL
- 🎭 Informar gênero
- 👤 Informar protagonista
- 🗑️ Remover animes da lista
- 🔄 Atualização dinâmica da interface utilizando JavaScript

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📷 Demonstração

O sistema permite cadastrar animes informando:

- Título
- Gênero
- Protagonista
- Foto (URL)

Após o cadastro, os animes são exibidos em cards na tela com suas informações e opção de exclusão.
